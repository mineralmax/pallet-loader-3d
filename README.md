# Pallet Loader 3D

A 3D box-stacking game: load 28 boxes onto pallets using as few pallets as possible.

- Open `index.html` in a browser (needs internet for three.js and cannon-es from a CDN).
- Boxes squish under load and are permanently crushed past their MAX LOAD. Fragile boxes have red tape.
- **🤖 Computer plays** (or press `T`) lets the computer load the truck. ×3 / ×8 speed it up.
- Controls: mouse aim, click/Space place, `R` turn, `F` flip on side, arrows nudge, `Q`/`E` or drag to orbit, scroll to zoom.

`2d/pallet-loader-2d.html` is the original 2D version (Matter.js).
